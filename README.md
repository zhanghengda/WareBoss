# WareBoss｜手机本地仓库

WareBoss 是一个本地优先的进销存工具，适合只在一台手机上使用。商品、库存、出入库流水保存在手机浏览器的 IndexedDB 中，不需要 Node.js API、云数据库或联网后端。

## 使用方式

首次在电脑上运行：

```powershell
npm start
```

打开 `http://localhost:3000`。手机访问时，可将项目部署到任意静态 HTTPS 站点后打开；数据仍只写入该手机浏览器。支持 PWA 的手机浏览器可通过“添加到主屏幕”安装成独立应用，并在首次加载后离线使用。

## GitHub Pages 托管

本项目已包含 `.github/workflows/deploy-pages.yml`。将整个项目推送到 GitHub 后，在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**；推送到 `main` 分支即会自动发布。GitHub Pages 只托管页面文件，不保存业务数据；每一台手机都有独立的本机数据和备份文件。

## 本地数据与备份

- 数据写入：手机本机 IndexedDB
- 导出：进入“数据备份”，下载完整 JSON 文件
- 恢复：选择此前导出的 JSON 文件；导入会覆盖当前手机数据
- 建议：每周备份一次，换手机或清理浏览器数据前务必先导出

## 已实现

- 商品、库存、采购入库、销售出库和流水
- 出库库存不足拦截
- 所有修改操作二次确认
- 表单误点遮罩层不会丢失输入内容
- 离线 PWA 缓存与本机 JSON 备份/恢复

## 说明

本机版不支持多台手机自动同步；不同手机上的数据相互独立。若以后需要多人、多设备共享数据，可保留当前 UI 并另行接入云端 PostgreSQL 同步服务。
